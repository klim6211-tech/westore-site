**요식업 사장님(예비창업자 + 기존 사장)을 향한 소비자형 SaaS 랜딩. 토스처럼 정교하고 애플 제품 페이지처럼

개념은 하나만 민다: **"흩어진 것이 하나로 모인다."** 모든 연출이 이 한 문장을 반복한다.

## 2. 기술 선택 (조사 근거 포함, 2026-09-03 GitHub API 실측)

| 역할 | 선택 | 근거 |
|---|---|---|
| 뼈대 | **Astro 5 + React 아일랜드 + Tailwind** | 정적 HTML이 나가서 검색·속도가 좋다. 움직이는 구역만 React. 관제웹과 같은 Vite 계열이라 낯설지 않다 |
| 일반 애니메이션 | **Motion**(구 Framer Motion) ⭐33,460 MIT | 스프링·등장·레이아웃 전환. `pick-ui-library` 스킬의 선택과 같다 |
| 스크롤 서사 | **GSAP ScrollTrigger** — 2024년부터 **전부 무료**(gsap.com/pricing 실측) | 고정 화면 + 스크롤 진행에 따른 전환의 표준 |
| 부드러운 스크롤 | **Lenis** ⭐15,667 MIT | 스크롤 서사가 뚝뚝 끊기지 않게 |
| 3D | **React Three Fiber + drei** ⭐31,900 MIT | 히어로의 글로시 W 리본 심볼 하나만. 3D를 여기저기 쓰지 않는다 |
| 완성 부품 | **Magic UI** ⭐22,140 MIT (복붙형) + motion-primitives ⭐6,188 MIT | 숫자 굴러가기, 글자 등장, 빛 테두리 카드 같은 것 |
| 배포 | **Cloudflare Pages** | 관제웹과 같은 곳. 미리보기 주소가 공짜로 생겨 청림님이 먼저 보고 바꿀 수 있다 |

**안 쓰는 것과 이유**
- React Bits ⭐46,645 — 가장 인기지만 라이선스가 표준 MIT 표기가 아니다(GitHub `NOASSERTION`). 상업 사용 조건을 읽기 전엔 안 쓴다.
- 통짜 템플릿(SaaS 스타터 킷) — 2026 수상작 분석의 "지는 것" 1순위가 복붙 템플릿이다. 부품은 가져오되 틀은 우리 카피에 맞춰 짠다.
- Spline 같은 노코드 3D — 무료 티어 워터마크·용량 문제. W 리본은 R3F 안에서 직접 만든다.

## 3. 연출 설계 — 개념 "흩어진 것이 하나로"

| 섹션 | 연출 | 기술 |
|---|---|---|
| **HERO** | 배경에 글로시 3D W 리본이 천천히 돌고 마우스에 살짝 기운다. 가운데 폰 목업, 주변 5장 카드(오늘 매출·지금 근무·오늘 발주·새 리뷰·이번 달 급여)가 **흩어진 상태에서 날아와 자리를 잡는다**. 숫자는 굴러서 도착 | R3F(W), Motion(카드), NumberFlow(숫자) |
| **3. 두 갈래** | 화면을 좌우로 갈라 각 갈래에 마우스를 올리면 그쪽이 넓어진다. 폰에서는 위아래 | CSS + Motion |
| **4. PROBLEM** | 카톡·엑셀·메모장·POS·리뷰 6개 조각이 화면 곳곳에 떠 있다가 스크롤하면 **"사장님의 기억"** 한 점으로 빨려 들어간다 | GSAP ScrollTrigger |
| **5. 선언** | 화면을 비우고 문장만. 글자가 한 줄씩 밝아진다 | Motion |
| **6. ALL-IN-ONE** | 8개 기능 카드가 격자로. 마우스 따라 빛 테두리 | Magic UI |
| **10. 기능 상세** | **폰이 화면에 고정**되고 스크롤할 때마다 폰 속 화면이 바뀐다(홈→리뷰→근무→발주→레시피→체크리스트→직원). 애플 제품 페이지 방식 | GSAP pin + 실제 앱 스크린샷 |
| **11. 시스템 체감** | 직원 아바타가 바뀌어도 레시피·체크리스트·근무·발주 카드는 그 자리에 남는다 | Motion layout |
| **영상** | 어제 만든 26초 광고(`media/westore-ad-v1.mp4`)를 **스크롤로 재생 위치를 넘기는** 구역 하나. 소리 없음 | 프레임 시퀀스 + ScrollTrigger |
| **13. 추구하는 가게** | 네 문장이 스크롤에 맞춰 하나씩 | Motion |
| **17. 요금** | 무료 / PRO 두 장. 지금 사이트 표와 환불 규정 원문 그대로 아래 붙임 | 정적 |

**절제 규칙**: 한 화면에 움직이는 것은 하나. 3D는 히어로에만. `prefers-reduced-motion`이면 전부 정지 이미지로.
모바일에서는 3D를 끄고 미리 찍은 이미지로 대체. Lighthouse 모바일 90 이상을 통과 기준으로 둔다.
