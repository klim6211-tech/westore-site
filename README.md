# 위스토어 홈페이지

`westoreapp.com` 으로 서비스되는 소개·요금제 페이지.

PG(카드결제) 심사와 앱스토어 심사에서 이 주소를 본다. 그래서 아래 다섯 가지가
반드시 살아 있어야 한다 — 하나라도 빠지면 심사에서 반려된다.

1. 무엇을 파는지 (서비스 소개)
2. 가격 (요금제)
3. 환불·해지 규정
4. 사업자정보 (상호·대표자·사업자등록번호·주소·연락처)
5. 문의처

요금제 정본은 `~/apps/storehub/docs/pricing-2026-08-31.md` 다.
여기 숫자를 고칠 땐 그 문서도 같이 고친다.
